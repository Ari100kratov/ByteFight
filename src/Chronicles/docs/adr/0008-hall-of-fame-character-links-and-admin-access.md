# ADR 0008: Ссылки из Зала славы и административный доступ

## Статус

Принято

## Контекст

`Chronicles` показывает публичные номинации и имена персонажей, но карточка персонажа содержит пользовательские данные и код поведения.
Обычный пользователь не должен получать ссылку на карточку чужого персонажа из Зала славы.
При этом администратору нужна возможность открывать такие карточки для поддержки и модерации.

## Решение

На frontend карточка номинанта в Зале славы становится ссылкой только для пользователя с ролью `admin`.
Для обычных пользователей карточка остается статичной: имя персонажа, имя игрока, класс, специализация и результат видны, но перехода нет.

На backend доступ к пользовательским ресурсам централизуется через `IUserAccessService`.
Он разрешает доступ владельцу ресурса или пользователю с ролью `admin`.
Роль администратора читается через инфраструктурный provider с `IMemoryCache`, чтобы не выполнять запрос к БД на каждый handler.

## Последствия

- Обычные пользователи не могут открыть чужую карточку персонажа через UI.
- Backend остается источником истины: ручной ввод URL все равно проходит проверку доступа.
- Проверки владения становятся менее дублирующимися и учитывают администратора единообразно.
- При изменении ролей нужно инвалидировать кэш пользователя или дождаться истечения TTL.
