# Документация Chronicles

Этот каталог содержит архитектурные решения и пояснения по подсистеме `Chronicles`.

## Содержимое

- `adr/0001-bounded-context.md`
  Границы контекста, ответственность сервиса и причины выделения в отдельную подсистему.
- `adr/0002-processing-model.md`
  Production-модель обработки через `Outbox -> Inbox -> Projection`.
- `adr/0003-integration-with-gameruntime.md`
  Интеграция с `GameRuntime`, transport-граница и роль backfill-механизма.
- `adr/0004-application-contracts.md`
  Use-case модель, общие application-абстракции и отказ от локального дублирования.
- `adr/0005-data-model-and-localization.md`
  Структура данных хроник, правила хранения и русскоязычные бизнес-данные.
- `adr/0006-worker-operations.md`
  Модель фонового воркера, import/projection pipeline и эксплуатационные особенности.
- `adr/0007-migrator-and-first-run-backfill.md`
  Отдельный мигратор, порядок старта сервисов и первичная догонка завершённых сессий.
- `adr/0008-hall-of-fame-character-links-and-admin-access.md`
  Правила ссылок из Зала славы на карточки персонажей и административный доступ к пользовательским данным.

## Как читать

1. Начать с `0001`, чтобы понять границы и назначение сервиса.
2. Затем прочитать `0002` и `0003`, чтобы понять поток данных и интеграцию.
3. После этого перейти к `0004` и `0005`, если нужен уровень проектирования кода и схемы данных.
4. `0006` полезен для запуска, эксплуатации и будущего масштабирования.
